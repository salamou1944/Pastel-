# Customer Template

Create a customer by changing configuration, not runtime code.

## Copy boundary
- `config.js` — customer identity, verified knowledge, channels and presentation.
- `assets/` — only customer-approved assets with checked rights.

## Keep shared
- UI
- chat flow
- truth policy
- voice fallback
- 3D runtime
- contact actions
- verification workflow

## Acceptance checklist
- [ ] Customer facts verified
- [ ] No unsupported claims
- [ ] Contact links tested
- [ ] Avatar rights checked
- [ ] Public deployment succeeds
- [ ] Browser tested on phone
- [ ] QR points to the verified public URL
- [ ] Customer sees the final page before commercial delivery
